A simple console-based Student Management System built using C++. It allows users to manage student records using file handling.

Features:
- Add Student
- Display All Students
- Search Student
- Delete Student
- Update Student

Concepts Used:
- Classes & Objects
- File Handling (fstream)
- Functions
- Conditional Statements

Future Improvements:
- Search by Name (not only by roll number)
- Show Topper Student
- Show Average Marks
- Sort Students by Marks
- Count Students
